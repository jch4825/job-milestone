# [PRD] 직업 마1스톤 (Job Milestone) 제품 요구사항 정의서

---

## 1. 프로젝트 개요 (Overview)

*   **프로젝트명:** 직업 마1스톤
*   **장르:** 인터랙티브 직업 교육용 비주얼 노벨 & 상황 대응 시뮬레이션
*   **타깃 사용자:** 특수학교 전공과 및 고등학교 발달장애 학생, 직업재활 훈련생 (취업 준비 및 초기 현장 적응 단계)
*   **배포 플랫폼:** **Web (HTML5/CSS3/ES Modules)** 및 **Electron 데스크톱 크로스플랫폼 앱** (Windows / macOS / Linux)
*   **기본 배경:** 베이커리 & 디저트 카페 매장 '마일스톤'
*   **핵심 목적:**
    1. 발달장애 학생이 직면하는 **직무 루틴 확립**, **돌발 상황 대처(솔직한 즉시 보고)**, **직장 내 공사 구분 및 대인관계**를 실패에 대한 불안 없이 안전하게 시뮬레이션하고 체득.
    2. **온디바이스 로컬 LLM(Gemma 2B급)** 기반의 1:1 대화형 면접을 통해 실제 취업 면접 상황을 다각도로 연습.
    3. **페르소나 5(Persona 5) 스타일의 감각적인 모션 그래픽**을 결합하여 학습 몰입도와 성취감을 극대화.

## 2. 비주얼 아트 디렉션: 페르소나 5 (Persona 5) 스타일 모션 그래픽

본 프로젝트는 지루하고 딱딱한 기존 직업 훈련 교재의 틀을 깨고, 학생들에게 강렬한 동기부여와 시각적 즐거움을 제공하기 위해 **페르소나 5 스타일의 펑크·팝아트 모션 그래픽**을 전면 채택합니다.

### 2.1. 시각 톤앤매너 및 컬러 팔레트
*   **주요 색상:**
    *   **Crimson Red (`#E60012`):** 에너지, 행동, 긴장감과 열정을 상징하는 메인 테마 컬러.
    *   **Jet Black (`#0C0C10`) & Charcoal (`#1C1C24`):** 높은 명도 대비를 완성하는 딥 배경 컬러.
    *   **Stark White (`#FFFFFF`):** 텍스트 및 프레임 경계선의 가독성을 보장하는 순백색.
    *   **Vivid Yellow (`#FFD200`):** 힌트, 점장님 메모 포스트잇, 성공 하이라이트 액센트.
*   **기하학적 스타일:**
    *   비대칭 사선 스큐(Skew -5° ~ -8°), 찢어진 종이 파편 질감(Ragged edges), 별 배지(Star Badges).
    *   코믹스 풍의 할프톤(Halftone) 도트 패턴 배경 레이어.

### 2.2. 모션 그래픽 연출 명세
*   **다이내믹 컷인 (Cut-In Eyes Banner):** 올바른 행동을 하거나 면접에서 긍정적 답변을 했을 때 화면을 번쩍이며 가로지르는 캐릭터 컷인 연출.
*   **슬래시 트랜지션 (Slash Transition):** 씬 전환 시 붉은 대각선 궤적이 화면을 가르며 전환.
*   **올아웃 어택 피니시 (All-Out Attack Finish):** 챕터 완료 및 계약서 서명 완료 시 전체 화면을 붉게 물들이며 대형 타이포그래피로 성공을 축하하는 피니시 연출.
*   **발달장애 인지 배려 (Accessibility Consideration):** 과도하게 깜빡이는 광과민성 플래시(Strobe)는 철저히 배제하고, 글자의 크기와 고대비를 유지하여 시각적 피로도를 낮추고 명확한 정보 인지를 유도.

### 2.3. 비주얼 & UX 디자인 벤치마킹 레퍼런스
*   **공식 영상 레퍼런스:** [비주얼노벨 '그녀의 하수인' 프롤로그 연출 분석 영상 (YouTube)](https://www.youtube.com/watch?v=xkzdeDArbEQ)
*   **핵심 벤치마킹 및 차용 요소:**
    1.  **시네마틱 카메라 줌/펀치인 (Punch-in Zoom):** 긴장감 있는 대화(점장의 날카로운 질문, 연우의 결심) 시 인물 상반신/눈매로 순간 줌인하여 몰입감 극대화.
    2.  **화면 분할 및 앵글 전환 (Dynamic Split-Screen):** 화자 간의 팽팽한 시선 교환 시 사선 분할 프레임 및 캐릭터 클로즈업 컷인 활용.
    3.  **감각적인 UI 타이포그래피:** 상황의 긴장도와 감정에 따른 폰트 크기 강약 조절 및 대사창 하이라이트 박스 연출.
    4.  **입체적인 레이어 심도 (Depth & Motion):** 배경(원경)과 캐릭터(중경), 대화 UI(근경) 간의 리드미컬한 패닝 및 슬라이드 트랜지션 적용.

## 3. 기술 아키텍처 및 플랫폼 전략

```
┌────────────────────────────────────────────────────────┐
│            Electron / Web 브라우저 렌더러              │
│  ┌───────────────────┐  ┌───────────────────────────┐  │
│  │ P5 모션 그래픽 UI │  │ 대화 / 카드 시뮬레이터    │  │
│  └────────┬──────────┘  └─────────────┬─────────────┘  │
│           │                           │                │
│  ┌────────▼───────────────────────────▼─────────────┐  │
│  │    3대 멀티모달 입력 레이어 (버튼 / 타자 / STT)   │  │
│  └────────────────────────┬─────────────────────────┘  │
└───────────────────────────┼────────────────────────────┘
                            │
               ┌────────────▼─────────────┐
               │    LLM Interview Adapter │
               └────────────┬─────────────┘
                            │
         ┌──────────────────┴──────────────────┐
         ▼                                     ▼
┌──────────────────┐                  ┌──────────────────┐
│ 로컬 Ollama API   │                  │ Offline Fallback │
│ (gemma4 e2b /    │ (서버 미구동 시) │ Rule-Based Mock  │
│  gemma:2b)       │ ───────────────▶ │ Simulator        │
└──────────────────┘                  └──────────────────┘
```

### 3.1. Electron 포팅 기반 설계
*   **하이브리드 구조:** 순수 웹 표준(HTML5 + Modern CSS + ES Modules)으로 개발되어 브라우저에서 즉시 실행 가능하며, Electron `main.js` 및 `preload.js`를 통해 데스크톱 네이티브 앱으로 1-Click 패키징 가능.
*   **IPC 통신 채널:** Electron 환경에서는 렌더러의 보안 샌드박스를 준수하면서 메인 프로세스를 통해 로컬 바이너리 및 LLM 엔드포인트와 안전하게 통신.

### 3.2. 온디바이스 로컬 LLM (Gemma 2B / e2b) 연동
*   **모델 스펙:** `gemma4 e2b` / `gemma:2b` 등 20~40억 파라미터급 초경량 온디바이스 LLM.
*   **e2b 초압축 컨텍스트 엔지니어링 (핵심):**
    *   **초압축 역할 프롬프트:** e2b의 짧은 컨텍스트 윈도우와 주의력 분산을 방지하기 위해 문장형 장문을 배제하고 `[역할]-[상대]-[규칙]`의 고밀도 Key-Value 포맷으로 시스템 프롬프트 압축.
    *   **슬라이딩 윈도우(Sliding Window) 히스토리:** 전체 대화를 무한정 쌓지 않고 `시스템 프롬프트 1개 + 최근 1~2턴`만 슬라이싱하여 전송, 토큰 오버플로우와 지시 망각을 원천 차단.
*   **구동 환경:** Ollama (`http://localhost:11434`), LM Studio, 또는 Electron 내장 프로세스.
*   **무중단 오프라인 보장:** 네트워크 단절이나 로컬 LLM 서버가 실행되지 않은 환경에서도 특수교육 시나리오 규칙 기반의 **Rule-based Fallback Mock**이 자동으로 작동하여 게임 진행이 중단되지 않음.

## 4. 3막 구조 내러티브 & 상세 시나리오

```
[Chapter 1: 첫 관문] ───────▶ [Chapter 2: 일상 루틴] ───────▶ [Chapter 3: 클라이맥스]
 (Gemma 면접 & 3대 입력          (점장 메모 단서 & 3지선다        (피크타임 위기 극복 &
  근로계약서 서명)               그림 카드 선택 루틴)             정식 크루 배지 수여)
```

### 4.1. Chapter 1: 첫 관문 (면접과 계약) - [중점 구현]

#### A. 멘토 도현과의 사전 대화 & 긴장 완화 분기
*   매장 앞 도착 후 긴장한 연우를 위해 선임 멘토 도현이 등장.
*   선택 분기:
    1. *“심호흡을 크게 하고 긴장을 푼다”* ➜ 도현의 호흡 가이드 및 정서적 안정.
    2. *“거울을 보며 유니폼과 옷매무새를 단정히 한다”* ➜ 복장 단정의 중요성 피드백.

#### B. Gemma 2B 기반 실시간 대화형 면접
*   **면접관:** 베이커리 카페 '마일스톤' 점장님.
*   **점장님 시스템 프롬프트 원칙:**
    *   따뜻하고 수용적인 어조(~해요, ~군요).
    *   2줄 이내의 짧고 명료한 문장 구성.
    *   솔직하게 모른다고 하거나 도움을 요청하는 태도를 최우선으로 칭찬.
*   **질문 단계:**
    *   *1단계 (지원 동기 및 강점):* “우리 카페에 지원한 이유와 자신 있는 일은 무엇인가요?”
    *   *2단계 (돌발 상황 및 보고 태도):* “만약 일하다가 컵을 깨거나 모르는 일이 생기면 어떻게 행동할 건가요?”

#### C. 발달장애 학생 맞춤형 3대 입력 인터페이스
학생 개개인의 인지적·신체적 특성에 따라 원하는 입력 방식을 자유롭게 선택:
1.  **버튼 클릭형 (Easy AAC Chips):** 문장 구성이 어려운 학생을 위한 추천 모범 답변 버튼 (원클릭 응답).
2.  **타자형 (Keyboard Input):** 키보드 입력을 선호하는 학생을 위한 텍스트 입력창.
3.  **음성 입력형 (STT / Web Speech API):** 텍스트 입력이 느리거나 부담스러운 학생이 마이크 버튼을 누르고 음성으로 직접 말할 수 있는 음성 인식 시스템.

#### D. 시각적 근로계약서 확인 및 서명
*   면접 통과 후 점장님이 근로계약서를 화면에 제시.
*   핵심 근로 조건(시급, 주당 근무시간, 휴게시간 원칙)을 시각적으로 확인.
*   연우가 화면의 계약서에 직접 **[전자 서명(도장 날인)]**을 클릭하여 정식 크루로 채용되는 성취감 부여.

### 4.2. Chapter 2: 일상 루틴과 이벤트 (본편)

*   **학습 목표:** 직무 순서화(Task Chaining), 메모 확인 습관화, 감정 조절.
*   **핵심 인터페이스:**
    1.  **점장님의 포스트잇 메모 (상시 노출):** 화면 우측 상단에 당일의 업무 수칙을 오픈북 형태로 제시.
    2.  **3지선다 그림 카드 트레이:** 직관적인 픽토그램 아이콘 + 대상+동사 형태의 명확한 행동 텍스트.
*   **상호작용 원칙 (Non-Punitive Design):**
    *   **정답 선택 시:** P5 컷인 발동, 경쾌한 성공 사운드, 멘토의 즉각적인 칭찬 대사.
    *   **오답/순서 오류 시:** 어떠한 감점이나 실패(Game-Over)도 주지 않음. 멘토 도현이 점장님 메모를 상기시키는 친절한 힌트 대사를 건네며 올바른 카드를 재선택할 수 있도록 유도.
*   **5일간의 루틴 테마:**
    *   *Day 1:* 출근 인사, 유니폼 착용, 손 씻기 6단계.
    *   *Day 2:* 점장 메모 확인, 컵 및 소모품 채우기, 매장 환기.
    *   *Day 3:* 손님 인사, 주문 접수 보조, 트레이 전달.
    *   *Day 4:* 음료 시럽을 쏟았을 때 즉각적인 솔직 보고 및 청소.
    *   *Day 5:* 매장 마감 정돈, 멘토와의 휴게 시간 티타임(직장 내 에티켓).

---

### 4.3. Chapter 3: 클라이맥스 (독립 직업인으로의 도약)

*   **학습 목표:** 복합 상황 속 우선순위 판단, 침착한 대처, 자립적 성취감.
*   **주요 에피소드:**
    *   러시아워 피크 타임에 단체 손님 주문 쇄도 및 제빙기 일시 이상.
    *   연우가 심호흡을 하고 배운 수칙대로 우선순위(보고 ➜ 안전 확보 ➜ 안내)에 따라 순차 대응.
    *   점장님이 연우의 책임감 있는 위기 대처를 인정하고 **정식 정규 크루 배지**를 수여.
    *   P5 스타일의 대형 All-Out Attack 피니시 배너와 함께 엔딩 크레딧 롤.

## 5. 기능 요구사항 명세 (Functional Requirements)

| 모듈 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **FR-01** | 대화 및 내러티브 엔진 | 대사 타이핑 연출, 화자 표시, 캐릭터 스탠딩 활성화/비활성화 명암 제어 |

| **FR-06** | 로컬 LLM 면접 인터페이스 | Gemma 2B 기반 실시간 대화 생성 (Ollama / IPC 연동 및 Fallback Mock 지원) |

| **FR-08** | Electron 패키징 규격 | `package.json`, `main.js`, `preload.js` 구성을 통한 데스크톱 네이티브 앱 실행 지원 |

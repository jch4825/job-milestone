## 씬 4. [돌발 이벤트] 시럽을 쏟았을 때의 정직한 보고

모든 준비가 순조롭게 끝나는 줄 알았다.
마지막으로 바닐라 시럽 통을 받침대에 올려놓으려던 순간이었다.

툭—

손에 힘이 살짝 빠졌다.
시럽 통 뚜껑이 덜 닫혀 있었는지, 진득한 갈색 시럽이 카운터 위로 주르륵 쏟아졌다.

철렁—

심장이 내려앉았다.
달콤한 바닐라 냄새가 끈적하게 퍼져나갔다.
얼굴이 뜨거워지고 손끝이 굳었다.
'어떡하지? 내가 실수를 했어. 혼나면 어떡하지?'
발달장애 학생이 가장 무서워하는 순간. 바로 실수했을 때다.

그때, 벽에 붙은 노란 포스트잇 3번이 눈에 들어왔다.
**[3. 실수하면 즉시 선배에게 말하기 (정직한 보고)]**

도현 선배는 뒤돌아서 커피 원두를 갈고 있었다.
아직 내가 시럽을 쏟은 걸 모른다.

---

### [3지선다 그림 카드 트레이]
* **[카드 1 - 오답]:** 🙈 **[모르는 척 다른 곳으로 피한다]** *(아이콘: 도망가는 발자국)*
* **[카드 2 - 정답]:** 🗣️ **[선배에게 즉시 보고하고 함께 닦기]** *(아이콘: 말하는 사람 & 행주)*
* **[카드 3 - 오답]:** 😭 **[무서워서 눈을 감고 가만히 있는다]** *(아이콘: 슬픈 표정)*

---

```

'안 돼. 모르는 척하면 시럽이 굳어서 다른 사람이 밟고 미끄러질 수 있어.

```

#### ▶ [카드 3 (가만히 있는다) 선택 시 - 힌트]
```

'무섭다고 가만히 있으면 안 돼.
 점장님도 실수했을 땐 바로 도와달라고 하셨잖아. 용기를 내자.'
```

#### ▶ [카드 2 (선배에게 즉시 보고하고 함께 닦기) 선택 시 - 정답!]
*연출 큐: 연우의 결심 컷인! "HONEST REPORT!"*

나는 숨을 크게 들이쉬고 도현 선배를 불렀다.

```
연우
"선배님! 제가…… 시럽을 쏟았습니다!"
```

목소리가 조금 떨렸지만, 또박또박 말했다.
도현 선배가 뒤를 돌아보았다.
화를 낼까 봐 눈을 질끈 감았다.
하지만 도현 선배는 웃으며 행주 두 장을 들고 다가왔다.

```
도현
"연우 씨, 아주 잘했어요!"
```

눈을 떴다. 선배는 웃고 있었다.

```
연우
"……혼 안 내시나요?"
```

```
도현
"혼을 왜 내요?
 시럽은 닦으면 그만이지만, 숨기면 손님이 다쳐요.
 곧바로 나한테 솔직하게 말해준 게 백배 천배 훌륭한 거예요.
 자, 이 젖은 행주로 같이 쓱싹 닦아볼까요?"
```

선배와 함께 카운터를 닦았다.

1분도 안 걸려서 카운터가 다시 반짝반짝해졌다.

가슴에 꽉 차 있던 두려움이 사르르 녹아내렸다.
실수를 해도 괜찮다. 솔직하게 말하고 같이 해결하면 된다.

*시스템: 성장 마일스톤 별 1개 획득! (★★★☆☆)*

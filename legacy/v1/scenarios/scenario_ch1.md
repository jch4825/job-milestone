### — 시나리오 스크립트 (쉬운 어휘 & 담백한 직관적 스타일)

---

## [등장인물]
* **연우 (주인공, 20세):** 특수학교 전공과 졸업반. 약속과 순서를 정확하게 지키는 것을 좋아한다. 처음 보는 사람 앞에서는 긴장을 많이 한다.
* **강도현 (선임 멘토, 26세):** 카페 '마일스톤'의 3년 차 선임 바리스타. 차분하고 친절하며, 연우가 일하는 순서를 잘 배울 수 있도록 옆에서 돕는다.
* **박건우 (점장, 42세):** 카페 '마일스톤'의 점장님. 규칙과 위생을 아주 중요하게 생각하지만, 솔직하고 성실한 직원을 따뜻하게 칭찬해 준다.

## 씬 1. 문밖의 선배 (프롤로그 & 긴장 완화)

### [배경: 카페 마일스톤 정문 앞 / 오전 8시 50분]
*연출 큐: 화면에 흑백 도트 배경과 붉은색 테두리가 깔린다. 유리문 안쪽에서 갓 구운 빵 냄새가 난다.*

시계를 보았다.
오전 8시 50분.
면접 시간 10분 전이다.

나는 매장 문 앞에 서서 옷을 확인했다.
단추가 잘 잠겼는지 확인한다. 한 번, 두 번, 세 번.
세 번 확인하니 마음이 조금 편안해졌다.

달칵—

유리문이 열리며 검은 앞치마를 두른 남자가 나왔다.
검은 안경을 쓴 바리스타 선배였다.
그가 나를 보며 친절하게 웃었다.

```
도현
"안녕하세요! 오늘 9시에 면접 보러 온 연우 씨 맞죠?"
```

나는 허리를 숙여 인사했다.

```
연우
"네! 안녕하세요."
```

```
도현
"많이 긴장했죠? 어깨에 힘을 조금 빼도 괜찮아요.
 우리 점장님이 조금 무뚝뚝해 보여도, 아주 친절한 분이거든요."
```

도현 선배가 내 눈을 보며 다정하게 말했다.

```
도현
"들어가기 전에 우리 하나만 해볼까요?
 연우 씨는 긴장될 때 어떻게 하면 마음이 편해지나요?"
```

---

### [기본 분기 1: 면접 직전의 행동 선택]

*UI 연출: P5 특유의 비스듬한 선택지 카드 2장이 화면 아래에 나타난다.*

* **선택지 A: [천천히 숨을 크게 쉬며 긴장을 푼다]**
* **선택지 B: [거울을 보며 단추와 옷을 바르게 정돈한다]**

#### ▶ [선택지 A 선택 시]
나는 가슴에 손을 올리고 숨을 천천히 쉬었다.
후— 하고 숨을 내쉬었다.

```
연우 (독백)
'하나, 둘, 셋.
 학교에서 선생님과 연습한 대로.'

도현
"아주 좋아요. 숨을 천천히 쉬면 마음이 편안해지죠.
 점장님 질문에 바로 대답하지 않아도 괜찮아요.
 숨 한번 편하게 쉬고, 생각난 대로 천천히 말하면 돼요."
```

#### ▶ [선택지 B 선택 시]
나는 가방에서 작은 거울을 꺼내 단추가 똑바로 잠겼는지 확인했다.

```
연우 (독백)
'옷을 단정하게 입는 건 좋은 인사 방법이다.'

도현
"오, 옷차림이 정말 단정하네요!
 우리 매장에서는 깨끗하고 단정한 옷차림이 제일 중요해요.
 아주 잘했어요. 자신감을 가져도 돼요!"
```

```
도현
"좋아요. 이제 문을 똑똑똑 두드리고 들어가 봐요."
```

## 씬 2. 점장실 앞 (노크와 입장)

### [배경: 카페 마일스톤 점장실 안 / 오전 8시 58분]
*연출 큐: 화면을 가르는 붉은 슬래시 전환. 책상 앞에 앉아 있는 점장님의 모습.*

똑. 똑. 똑.

```
점장
"네, 들어오세요."
```

점장님의 목소리가 들렸다.
문을 열고 들어가니 책상 위에 내 이력서가 놓여 있었다.
점장님이 나를 바라보았다.

```
점장
"연우 씨, 어서 와요.
 여기 의자에 편하게 앉아요."
```

나는 의자에 똑바로 앉았다. 두 손을 무릎 위에 단정하게 올렸다.

```
점장
"학교에서 빵 굽기와 카페 일을 열심히 배웠다고 들었어요.
 오늘 면접에서는 어려운 질문을 하지 않을 거예요.
 내가 묻는 말에 아는 대로, 솔직하게 이야기해 줄 수 있나요?"
```

```
연우
"네! 솔직하게 말씀드리겠습니다."
```

```
점장
"좋아요. 그럼 시작해 볼까요?"
```

## 씬 3. [핵심] 실시간 면접 (Gemma 2B 로컬 LLM)

*시스템 안내:*
* *우측 상단 [점장님의 메모: 1. 바른 자세로 인사하기 / 2. 모르는 것은 솔직히 묻기] 상시 노출.*
* *화면 아래에 3가지 입력 방법이 나타남:*
  1. *[버튼 클릭형 (원클릭 추천 문장)]*
  2. *[타자 입력형 (키보드로 글자 쓰기)]*
  3. *[음성 입력형 (마이크로 말하기)]*

---

### [질문 1: 지원 동기와 잘하는 일]

```
점장
"첫 번째 질문입니다.
 연우 씨는 우리 카페에서 어떤 일을 가장 자신 있게 잘할 수 있나요?"
```

#### ▶ 입력 선택 (버튼 / 타자 / 음성)
* **[추천 버튼 1]:** "카페를 좋아하고, 빵 포장과 컵 정리를 성실하게 잘할 수 있습니다!"
* **[추천 버튼 2]:** "정해진 규칙을 잘 지키고, 매장을 항상 깨끗하게 청소하겠습니다."
* **[추천 버튼 3]:** "배우는 속도는 조금 느려도, 포기하지 않고 끝까지 성실히 하겠습니다!"
* **[직접 쓰기 / 마이크 말하기]:** 학생이 직접 글자를 쓰거나 마이크로 말함.

#### ▶ 점장님의 답변 (Gemma 2B 로컬 AI 생성 예시)
```
점장
"자신이 잘하는 일을 정확하게 알고 있군요! 아주 좋습니다.
 빵을 포장하고 컵을 깨끗하게 정리하는 일은 우리 카페에서 정말 중요한 일이에요.
 성실하게 하겠다는 마음이 아주 마음에 듭니다."
```
*연출 큐: 점장님이 웃으며 고개를 끄덕인다.*

---

### [질문 2: 실수했을 때의 대처 방법 (가장 중요한 질문)]

```
점장
"두 번째 질문입니다.
 만약 일하다가 유리컵을 떨어뜨려 깨뜨렸거나,
 어떻게 해야 할지 모르는 일이 생기면 연우 씨는 어떻게 행동할 건가요?"
```

머릿속에 학교에서 배운 규칙이 떠올랐다.
*—실수했을 땐 절대 숨기지 말고, 즉시 솔직하게 말해야 한다.*

#### ▶ 입력 선택 (버튼 / 타자 / 음성)
* **[추천 버튼 1]:** "당황하지 않고, '점장님 제가 컵을 깨뜨렸습니다'라고 즉시 솔직하게 보고하겠습니다."
* **[추천 버튼 2]:** "다치지 않게 조심한 뒤, 선배님께 어떻게 치워야 하는지 물어보겠습니다."
* **[추천 버튼 3]:** "모르는 일이 생기면 혼자 하지 않고, 바로 '도와주세요'라고 말하겠습니다."
* **[직접 쓰기 / 마이크 말하기]:** 학생이 직접 입력.

#### ▶ 점장님의 답변 (Gemma 2B 로컬 AI 생성 예시)
```
점장
"참 훌륭한 대답입니다!
 일하다가 실수하는 건 괜찮아요. 다시 배우면 되니까요.
 하지만 실수를 숨기면 사람이 다칠 수 있어요.
 즉시 솔직하게 말하고 도움을 청하겠다는 연우 씨의 태도는 백 점 만점입니다!"
```

*연출 큐: P5 컷인 배너가 번쩍이며 경쾌한 성공 효과음이 울린다.*

# [직업 마1스톤] 제3막: 클라이맥스 (독립 직업인으로의 도약)
### — 시나리오 스크립트 (피크타임 대처 & 정규 크루 임명)

---

## [등장인물]
* **연우 (주인공, 20세):** 카페 '마일스톤'의 신입 직원. 배운 규칙과 순서를 지키며 조금씩 자신감을 얻고 있다.
* **강도현 (선임 멘토, 26세):** 연우와 손발을 맞추는 든든한 사수. 위기 상황에서도 흔들리지 않고 침착하게 역할을 나눈다.
* **박건우 (점장, 42세):** 연우의 성실한 성장을 지켜보고 진심으로 신뢰를 보내는 매장의 리더.

## 씬 1. 몰려드는 손님들 (피크타임의 시작)

### [배경: 카페 마일스톤 매장 홀 / 낮 12시 30분]
*연출 큐: 매장 안으로 경쾌한 재즈 피아노 음악 대신, 웅성거리는 사람들의 소리와 짤랑거리는 문방울 소리가 쉴 새 없이 울린다.*

낮 12시 30분.
점심시간 피크타임이다.

딸랑— 딸랑— 딸랑—!

매장 문이 열리며 회사원 열다섯 명이 한꺼번에 들어왔다.
순식간에 카운터 앞이 사람들로 가득 찼다.

"아이스 아메리카노 다섯 잔이요!"
"따뜻한 라떼 세 잔이랑 크루아상 네 개 포장해 주세요!"
"저희 시간이 별로 없는데 빨리 될까요?"

사람들의 말소리와 웅성거림이 파도처럼 쏟아졌다.
머릿속이 찌릿하고 귀가 멍멍해졌다.
발달장애가 있는 나에게 너무 많은 사람과 소음은 가장 무서운 자극이다.
발이 바닥에 달라붙은 것처럼 움직이지 않았다.

'소리가 너무 크다…… 어떡하지? 주문이 너무 많아.'

심장이 쿵쾅쿵쾅 뛰었다.
당장이라도 주방 구석으로 숨고 싶었다.

## 씬 2. 깊은 숨, 그리고 메모 확인

그때, 옆에서 커피 머신을 잡고 있던 도현 선배가 내 어깨를 톡톡 두드렸다.

```
도현
"연우 씨! 괜찮아요.
 손님이 많아도 한 번에 한 잔씩 만들면 돼요.
 우리 저기 점장님 메모 1번 볼까요?"
```

선배의 목소리를 듣고 고개를 돌렸다.
벽에 붙은 노란 포스트잇이 눈에 들어왔다.

---

### [화면 상시 노출: 피크타임 대처 수칙]
```
┌──────────────────────────────────────────────┐
│  📌 피크타임 대처 수칙                        │
│                                              │
│  1. 당황하지 않고 깊게 숨쉬기                │
│  2. 선배와 역할을 나누어 맡기                │
│  3. 한 번에 하나씩 차근차근 하기             │
└──────────────────────────────────────────────┘
```

가슴에 손을 얹었다.
후— 하—
숨을 세 번 깊게 쉬었다.
차가운 공기가 들어가자 심장 뛰는 소리가 조금씩 가라앉았다.

'그래. 도망치지 말자.
 혼자 다 하는 게 아니야. 선배님이랑 나눠서 하면 돼.'

## 씬 3. [클라이맥스 선택] 역할을 나누다 (3지선다 그림 카드)

*시스템 연출 명세:*
* *화면 아래에 3지선다 그림 카드가 나타난다.*
* *위기 상황에서 올바른 행동을 선택하는 핵심 분기.*

```
나 (연우): 주문이 한꺼번에 몰려왔다.
내가 지금 해야 할 가장 올바른 행동은 무엇일까?
```

### [3지선다 그림 카드 트레이]
* **[카드 1 - 오답]:** 😭 **[너무 무서워서 눈을 감고 가만히 있는다]** *(아이콘: 눈물)*
* **[카드 2 - 정답]:** 🤝 **[심호흡하고, 도현 선배와 역할을 나눈다]** *(아이콘: 손잡은 두 사람)*
* **[카드 3 - 오답]:** 🚪 **[당황해서 매장 밖으로 뛰어나간다]** *(아이콘: 열린 문)*

---

#### ▶ [카드 1 (가만히 있는다) 선택 시 - 힌트]
```
연우 (내면 힌트)
'무섭다고 가만히 서 있으면 손님들이 계속 기다려야 해.
 메모 2번처럼 도현 선배한테 역할을 나누자고 말해야 해.'
```

#### ▶ [카드 3 (뛰어나간다) 선택 시 - 힌트]
```
연우 (내면 힌트)
'도망치면 안 돼. 나는 카페 마일스톤의 정식 직원이야.
 선배님과 함께 해결할 수 있어.'
```

#### ▶ [카드 2 (선배와 역할을 나눈다) 선택 시 - 정답!]
*연출 큐: P5 컷인 발동! 연우의 단단한 눈빛 컷인과 함께 경쾌한 성공 효과음.*

나는 도현 선배를 똑바로 바라보며 말했다.

```
연우
"선배님! 제가 빵 포장과 컵 뚜껑 닫기를 맡겠습니다!
 음료는 선배님이 내려주실 수 있나요?"
```

도현 선배의 얼굴에 환한 미소가 번졌다.

```
도현
"좋아요, 완벽한 역할 분담이에요!
 음료 추출은 내가 할 테니, 연우 씨는 포장을 부탁해요!"
```

우리는 톱니바퀴처럼 움직이기 시작했다.
도현 선배가 에스프레소를 뽑아 얼음 잔에 부으면,
내가 정확한 크기의 뚜껑을 찾아 '딱' 소리가 나게 닫고 빨대를 꽂았다.
주문서에 적힌 대로 크루아상을 집게로 집어 위생 종이봉투에 담고 스티커를 붙였다.

하나씩, 차근차근.
손이 빨라졌다. 규칙대로 하니 하나도 헷갈리지 않았다.

```
연우
"주문하신 아이스 아메리카노 다섯 잔과 빵 나왔습니다!
 맛있게 드세요!"
```

손님이 웃으며 트레이를 받아 들었다.

"우와, 손이 정말 빠르시네요! 빵도 예쁘게 포장해 주셔서 고마워요."

가슴속에서 찌릿한 뿌듯함이 차올랐다.
손님에게 직접 고맙다는 말을 들었다.
내가 해냈다.

*시스템: 성장 마일스톤 별 1개 획득! (★★★★☆)*

## 씬 4. 점장님의 금빛 배지 (정규 크루 수여식)

오후 1시 30분.
폭풍 같던 점심시간이 끝나고 매장에 다시 조용한 음악이 흘렀다.
테이블을 닦고 컵을 정리하고 있을 때였다.

탁, 탁.

구두 굽 소리와 함께 박건우 점장님이 카운터 앞으로 걸어왔다.
점장님의 손에는 작은 검은색 상자가 들려 있었다.

```
점장
"연우 씨, 잠깐 이리 와봐요."
```

나는 앞치마에 손을 닦고 점장님 앞에 섰다.

```
점장
"아까 단체 손님이 몰려왔을 때, 주방 안쪽에서 지켜보고 있었어요.
 손님이 많아서 많이 놀랐을 텐데 도망치지 않더군요.
 당황하지 않고 깊게 숨을 쉰 뒤, 도현 씨와 역할을 나누어 차근차근 해냈어요."
```

점장님이 검은 상자를 열었다.
그 안에는 반짝반짝 빛나는 금빛 배지가 들어 있었다.
배지 한가운데에 **[MASTER CREW]**라는 글자가 새겨져 있었다.

```
점장
"일을 배우는 기술은 시간이 지나면 늘어납니다.
 하지만 위기 상황에서 규칙을 지키고, 동료와 정직하게 소통하는 마음은
 아무나 가질 수 없는 진짜 직업인의 자세예요."
```

점장님이 내 앞치마 가슴팍에 금빛 배지를 달아주었다.

```
점장
"오늘부로 연우 씨를 우리 카페 마일스톤의 정식 '정규 크루'로 인정합니다.
 정말 자랑스럽습니다, 연우 크루."
```

눈시울이 뜨거워졌다.
학교에서 매일 손 씻기와 인사 연습을 하던 날들이 스쳐 지나갔다.
나는 이제 혼자 힘으로 당당하게 일하는 직업인이 되었다.

```
연우
"감사합니다, 점장님!
 앞으로도 규칙을 지키고 성실하게 일하겠습니다!"
```

## 씬 5. 에필로그 (우리는 최고의 파트너)

*연출 큐:*
*화면 전체가 붉은색과 금빛으로 물들며 Persona 5 시그니처 컷씬 폭발!*
**[ MISSION COMPLETE : 독립 직업인으로의 성장 완결! ]**

도현 선배가 다가와 내 어깨를 툭 쳤다.
그리고 손바닥을 활짝 펴 보였다.

```
도현
"연우 크루! 하이파이브 한번 할까요?"
```

짝—!

손바닥이 부딪치며 경쾌한 소리가 울렸다.

```
도현
"축하해요, 연우 씨!
 이제 우리는 누구도 부럽지 않은 최고의 팀이에요.
 내일도 우리 신나게 커피 뽑아봐요!"
```

```
연우
"네, 선배님! 내일도 내일의 루틴을 지키겠습니다!"
```

창밖으로 따뜻한 오후 햇살이 쏟아져 들어왔다.
가슴에 달린 금빛 배지가 햇빛을 받아 눈부시게 빛나고 있었다.
나의 첫 번째 일터, 그리고 나의 마일스톤에서
나는 오늘도 한 걸음 더 앞으로 걸어간다.

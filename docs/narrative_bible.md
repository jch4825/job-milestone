# 직업 마1스톤: 내러티브 바이블 (v2.0)

> 이 문서는 이야기의 **단일 기준(Single Source of Truth)**입니다.
> 대사·장면·캐릭터를 새로 쓰거나 고칠 때는 반드시 이 문서와 맞는지 먼저 확인합니다.
> 실제 대사의 원본은 `js/data/episodes/*.js`에 있고, 읽기용 대본은 `scenarios/*.md`에 있습니다(`npm run export`로 생성).

## 1. 작품의 핵심

| 항목 | 내용 |
| :--- | :--- |
| **제목** | 직업 마1스톤 (Job Milestone). '1'은 **첫 번째 이정표**라는 뜻 |
| **한 줄 소개** | 스무 살 연우가 베이커리 카페 '마일스톤'에서 첫 출근부터 정규 크루가 되기까지 보내는 한 달. 실수해도 괜찮은 곳에서 **말하는 법, 묻는 법, 부탁하는 법, 돕는 법**을 배운다. |
| **캐치프레이즈** | **직장 생활, 해 보면서 배워요.** 되감아 다시 할 수 있는 나의 첫 직장. (처음 화면, `js/config.js`의 `TAGLINE`) |
| **주제문** | 실수했다고 끝나지 않는다. 말하면 함께 해결된다. 그리고 도움을 받던 사람이 언젠가 돕는 사람이 된다. |
| **톤** | 따뜻함 70 : 긴장 20 : 유머 10. 위기는 있지만 악의는 없다. 모든 어른은 연우를 **어른으로** 대한다. |
| **감정 키워드** | 두근거림 → 얼어붙음 → 안도 → 뿌듯함 → 당당함 → 뭉클함 |
| **플레이 시간** | 9개 에피소드 × 8~12분 = 약 90~110분 (수업 1차시에 1~2개 에피소드) |

### 1.1 이야기의 다섯 가지 약속 (Story Pillars)

1. **시행착오와 되감기**: 플레이어의 잘못된 선택은 **실제 결과**로 이어집니다(손님이 미끄러짐, 주문이 꼬임, 면접에서 떨어짐). 대신 회중시계로 **그 선택 바로 앞까지 곧바로 되감아** 다시 고를 수 있습니다. 결과를 직접 보고 원인을 깨닫는 것이 이 게임의 핵심 재미이자 배움입니다.
   - 이야기 속에서 연우가 하는 실수(시럽 사고 등)는 정해진 사건이며, 언제나 **보고 → 해결 → 안도**로 끝납니다. "실수는 말하면 해결된다"는 주제는 그대로입니다.
2. **보이는 규칙**: 규칙은 늘 노란 메모로 붙어 있습니다. 외우지 않아도 되는 가게입니다.
3. **스스로 말하기**: 연우의 성장은 '일을 잘하는 것'보다 **'필요한 말을 할 수 있게 되는 것'**으로 측정합니다.
   - 모르겠어요 · 다시 말해 주세요 · 도와주세요 · 잠깐 쉬어도 될까요 · 그건 어려워요 · 말해줘서 고마워요
4. **모두를 위한 도움**: 메모·귀마개·그림 카드 같은 도움은 연우만을 위한 특별 대우가 아닙니다. 점장도, 민재도, 도현도 각자의 도움을 쓰며 일합니다.
5. **동정도 영웅화도 없이**: 연우는 '불쌍한 사람'도 '감동을 주기 위한 사람'도 아닙니다. **평범하게 성실한 신입 직원**입니다.

## 2. 반복 모티프 (상징 장치)

| 모티프 | 의미 | 등장 → 회수 |
| :--- | :--- | :--- |
| **노란 메모** | 보이는 규칙, 보살핌, 이어지는 마음 | 엄마의 쪽지(프롤로그) → 점장의 오픈 메모(매일) → 점장의 비밀(3장) → **연우가 지호에게 쓰는 메모(3장 마무리)** |
| **하나, 둘, 셋** | 연우가 스스로 마음을 다스리는 방법 | 단추 세 번 확인(프롤로그) → 시럽 사건 숨 고르기(2일 차) → 피크타임 숨 세 번(3장) |
| **회중시계** | 점장의 신념: "시간 약속은 손님과의 약속" | 면접(1장) → 메모 비밀과 함께 아버지 이야기(3장) |
| **폴라로이드** | 소라가 찍는 '오늘의 한 장'. 함께한 시간의 증거 | 매 에피소드 사진 1장 획득 → 엔딩 사진 벽 |
| **귀마개** | 필요한 도움을 쓰는 것은 부끄럽지 않다 | 민재의 귀덮개(1일 차) → 면접에서 요청(선택) → 피크타임에서 사용(3장) |
| **"말해줘서 고마워요"** | 이 가게의 말버릇 | 도현(2일 차) → 점장(4일 차) → 연우가 지호에게(3장 마무리) |
| **문 앞의 첫인사** | 같은 장면, 다른 자리 | 도현이 긴장한 연우를 맞음(1장) → **연우가 긴장한 지호를 맞음(3장 마무리)** |

## 3. 세계관

### 3.1 해솔동
수도권의 평범한 동네입니다. 시장, 오래된 아파트, 새 오피스텔, 작은 공원이 섞여 있습니다.
연우의 집에서 카페까지는 **마을버스 '해솔07'로 네 정거장(약 12분)** 걸립니다. 정류장 이름은 '해솔시장 앞'에서 '마일스톤 카페 앞'까지입니다.

### 3.2 베이커리 카페 '마일스톤'
- **역사**: 8년 전 박건우 점장이 아버지의 동네 빵집 자리를 이어받아 문을 열었습니다. 간판의 이정표 로고는 아버지 가게의 낡은 나무 표지판에서 왔습니다.
- **가게 철학**: "외우지 않아도 되는 가게." 모든 규칙은 메모로, 모든 순서는 그림으로 붙어 있습니다.
- **영업**: 09:30 오픈. 오전에는 출근 손님, 12시부터 1시까지는 점심 피크입니다.
- **공간**: 홀(테이블 8개, 낮은 카운터 1칸), 카운터(포스기, 빵 진열장, 컵 보관대), 바(에스프레소 머신, 제빙기), 주방(오븐, 반죽기), 직원 공간(사물함, 거울, 손 씻는 곳, **메모 보드**), 점장실, 창고, 뒷문.
- **대표 메뉴**: 소금빵, 크루아상, 마일스톤 식빵, 초코 머핀 / 아메리카노, 카페라테, 바닐라라테, 따뜻한 우유, 오렌지주스.
- **오늘의 한 장**: 소라가 즉석카메라로 그날 가장 좋은 순간을 찍어 직원 공간 벽에 붙입니다.

### 3.3 연우의 근무 조건 (근로계약서 기준)
| 항목 | 내용 |
| :--- | :--- |
| 일하는 날 | 월요일 ~ 금요일 |
| 일하는 시간 | 09:00 ~ 13:30 (쉬는 시간 30분 포함, **실제로 일하는 시간 하루 4시간**) |
| 쉬는 시간 | 11:00 ~ 11:30 (4시간 일하면 30분 이상 쉬어야 합니다) |
| 일주일 일하는 시간 | 20시간 → 주 15시간 이상이므로 **주휴수당** 대상 |
| 시급 | 그해 최저임금 이상 (`js/config.js`의 `WAGE_TABLE`에서 연도별로 관리) |
| 월급날 | 매달 10일, 통장으로 |
| 하는 일 | 오픈 준비, 컵·비품 채우기, 빵 포장, 트레이 전달, 매장 정리 |

### 3.4 해솔특수학교 전공과
연우가 졸업을 앞두고 다니는 곳입니다. 담임 김선영 선생님은 '세 가지 약속'을 가르쳤습니다.
> **① 모르면 물어보기 ② 실수하면 말하기 ③ 힘들면 쉬겠다고 말하기**

이 세 가지 약속이 게임 전체의 **핵심 규칙**이며, 연우는 학교에서 배운 약속을 일터에서 하나씩 실제로 써 봅니다.

## 4. 등장인물

> 표기: 나이 / 역할 / 상징 색. 말투 예시는 실제 대사 작성의 기준입니다.

### 4.1 정연우: 주인공
**20세 / 해솔특수학교 전공과 졸업반 → 카페 마일스톤 신입 크루 / 마일스톤 레드**

- **외형**: 갈색 단발, 큰 갈색 눈. 흰 셔츠에 빨간 앞치마, 검은 바지, 흰 운동화. 왼손목에 엄마가 준 실 팔찌.
- **성격**: 정확하고 성실합니다. 약속과 순서를 좋아합니다. 사람의 이름과 주문을 잘 기억합니다.
- **좋아하는 것**: 갓 구운 빵 냄새, 컵이 딱 맞게 쌓이는 소리, 셋까지 세기, 노란색.
- **힘든 것**: 갑자기 나는 큰 소리, 여러 사람이 한꺼번에 말하는 것, "대충", "적당히", "그거" 같은 애매한 말. 실수하면 몸이 굳습니다.
- **배경**: 고등학교 현장실습 때 접시를 깨고 무서워서 말하지 못했습니다. 나중에 들켜서 크게 혼났고, 그 뒤로 **"실수하면 끝"**이라는 생각이 생겼습니다.
- **꿈**: 언젠가 내가 만든 빵을 파는 것, 그리고 첫 월급으로 엄마에게 선물하기.
- **말투**: 일터에서는 또박또박한 존댓말("~하겠습니다", "~해도 될까요?")을 씁니다. 속마음은 짧게 끊어 말합니다("괜찮아. 하나, 둘, 셋.").
- **성장 곡선**:
  1. 실수하면 끝이야 (두려움)
  2. 말하면 해결돼 (정직한 보고, 2일 차)
  3. 내게 필요한 걸 말해도 돼 (자기옹호, 4일 차와 3장)
  4. 나도 누군가를 도울 수 있어 (멘토, 3장 마무리)
  5. 내 하루는 내가 짠다 (자립, 4장) → 다음 이정표: 언젠가 내가 만든 빵 (엔딩)
- **절대 금지**: 서술에서 연우를 진단명으로 부르지 않습니다. 연우의 특성은 행동과 감각으로 **보여 줍니다.**

### 4.2 강도현: 선임 멘토
**26세 / 3년 차 바리스타, 연우의 사수 / 차콜 & 와인**

- **외형**: 검은 머리, 검은 뿔테 안경, 흰 셔츠, 회색 조끼, 와인색 넥타이. 생각할 때 안경을 밀어 올립니다.
- **성격**: 차분하고 다정합니다. 설명을 짧게 나누어 합니다.
- **말버릇**: "괜찮아요. 같이 해요." / "말해줘서 고마워요."
- **배경(5일 차 티타임에 공개)**: 첫 직장에서 우유 피처를 쏟고 혼날까 봐 대충 닦고 말하지 않았습니다. 그 바닥에서 손님이 미끄러져 손목을 다쳤습니다. 그날 들은 "왜 말 안 했어?"라는 말이 가장 아팠습니다. 그 뒤로 실수는 **혼낼 일이 아니라 말해줄 일**이라고 믿게 되었습니다.
- **약점과 성장**: 너무 빨리 도와줘서 연우가 해 볼 기회를 가끔 빼앗습니다. 3장에서는 "오늘은 연우 씨가 정해 줘요. 나는 뭘 할까요?"라고 말하며 한 걸음 물러섭니다.
- **교육적 역할**: 촉진(힌트)을 주는 사람입니다. 언제나 **왜 그런지 + 대신 무엇을 할지**를 함께 말합니다.

### 4.3 박건우: 점장
**42세 / 카페 마일스톤 창업자 / 슬레이트 & 골드**

- **외형**: 회녹색 머리, 짧은 수염, 검은 조끼, 남색 넥타이, 금색 회중시계. 앞치마 주머니에 'CAFE MILESTONE' 자수가 있습니다.
- **성격**: 말수가 적고 처음에는 무뚝뚝해 보입니다. 위생과 안전, 시간에는 엄격하지만 정직한 사람은 꼭 칭찬합니다.
- **신념**: "시간 약속은 손님과의 약속이에요." (빵집을 하던 아버지의 말)
- **비밀(3장에 공개)**: 어릴 때부터 긴 글과 말로만 들은 지시를 잘 기억하지 못했습니다. 그래서 **자기 자신을 위해** 메모를 쓰기 시작했습니다. "메모는 원래 나를 위해 쓰기 시작했어요. 그런데 써 보니까 모두가 편하더라고요."
- **직원을 지키는 사람**: 3장에서 반말과 고함을 하는 손님에게 "우리 직원에게 그렇게 말씀하시면 안 됩니다"라고 단호하게 말합니다.
- **교육적 역할**: 공정한 고용주의 모범입니다. 계약서 설명, 편의 제공, 직원 보호를 보여 줍니다.

### 4.4 한소라: 계산대 파트타이머
**23세 / 대학생(시각디자인과) / 코랄**

- **외형**: 포니테일, 동그란 안경, 앞치마에 펜 세 자루. 목에 즉석카메라를 걸고 다닙니다.
- **성격**: 밝고 빠릅니다. 말이 빨라서 "그거", "저기", "대충"을 자주 씁니다.
- **성장**: 1일 차에 연우의 확인 질문을 받고 자기가 애매하게 말했다는 것을 깨닫습니다. 그 뒤로 **그림 카드를 직접 그려** 연우에게 지시합니다. 게임 속 그림 카드 UI가 생긴 이유입니다.
- **교육적 역할**: 애매한 지시에 확인 질문으로 대처하는 연습 상대이자, '오늘의 한 장' 사진을 찍는 사람입니다.

### 4.5 오민재: 제빵 크루
**29세 / 5년 차 제빵 담당, 해솔특수학교 전공과 출신 / 밀가루 베이지**

- **외형**: 짧은 머리, 볼에 묻은 밀가루, 큰 귀덮개(소음 차단 이어머프)를 목에 걸고 다닙니다.
- **성격**: 말이 아주 짧고 조용합니다. 반죽 시간만큼은 1초도 틀리지 않습니다.
- **연우와의 관계**: 같은 학교 선배입니다. 연우가 보는 **'미래의 나'**입니다. "나도 처음엔 무서웠어."
- **명장면**: 1일 차에 반죽기 소리에 놀란 연우에게 자기 귀덮개를 보여 줍니다. "소리 큰 거 싫어. 그래서 이거 껴. 괜찮아."
- **교육적 역할**: 편의 도구를 당당하게 쓰는 모습을 보여 주는 롤모델입니다.

### 4.6 엄마 (이미정)
**48세 / 연우의 엄마 / 라벤더**

- 걱정이 많고 무엇이든 대신 해 주고 싶어 합니다. 연우 가방에 쪽지를 몰래 넣습니다.
- **쪽지**: "연우야, 모르면 물어보면 돼. 엄마는 연우를 믿어."
- **성장**: 데려다주려는 엄마(프롤로그) → 정류장에서 기다리는 엄마(5일 차) → **"이제 걱정 조금만 할게."(3장 마무리)** → **"엄마는 이제 걱정 대신 응원할게."(엔딩)**

### 4.7 김선영 선생님
**38세 / 해솔특수학교 전공과 담임 / 그린**

### 4.8 유지호: 새 신입 (3장 마무리)
**19세 / 다음 신입 크루 / 스카이 블루**

## 6. 에피소드 시놉시스와 감정 설계

### 프롤로그: 첫 출근길
- **목요일 밤 21:30, 연우의 방**: 알람을 7시에 맞추고, 엄마와 함께 '내일 준비물'을 챙깁니다(이력서, 신분증, 손수건, 교통카드). 엄마는 "내일 엄마가 차로 데려다줄게"라고 하지만 연우는 **"혼자 가 볼래요. 연습했어요."**라고 말합니다. 엄마의 얼굴이 잠깐 흔들립니다.
- **금요일 08:20, 버스 정류장**: 전광판에 '해솔07 · 3분 후'가 뜹니다. 같은 번호처럼 보이는 '해솔17'이 먼저 도착합니다(번호 끝까지 확인하기). 가방 앞주머니에서 **엄마의 쪽지**를 발견합니다. 숨을 세 번 쉬고 버스에 탑니다.
- **08:50, 카페 앞**: 유리문 너머로 빵 냄새가 납니다. 단추를 세 번 확인합니다. 그때 문이 열립니다.
- **감정 포인트**: 쪽지를 읽는 순간. 프롤로그의 배경음은 그 순간에만 피아노 한 음으로 바뀝니다.

### 1장: 첫 관문 (면접과 계약)
- 도현의 긴장 풀기(숨 고르기 또는 옷매무새 정리) → 노크 → 점장과 마주 앉기.
- **면접 4문항** (말하는 방법은 골라서, 써서, 말로 중에서 고릅니다)
  1. 잘할 수 있는 일 (강점 말하기)
  2. 컵을 깨뜨리면? (솔직한 보고)
  3. **일할 때 필요한 도움이 있나요?** (자기옹호, 선택에 따라 뒤의 이야기가 달라짐)
     - 귀마개 요청 → 1일 차에 민재가 공감하고, 3장에서 귀마개 사용
     - 순서를 그림으로 → 소라가 그림 카드를 만들어 옴
     - 천천히 하나씩 → 소라가 말 속도를 고침
     - 일하면서 말씀드릴게요 → 3장에서 그 자리에서 요청
  4. 궁금한 것 있어요? (질문하기. "없습니다"도 괜찮지만 점장이 질문의 가치를 알려 줌)
- 면접 중 언제든 **[다시 말해 주세요] [생각할 시간 주세요]**를 누를 수 있습니다. 둘 다 실제 면접에서 써도 되는 말입니다.
- **근로계약서**: 조항마다 듣기 버튼이 있습니다. 확인 질문 3개(출근 시간, 쉬는 시간, 월급날)를 계약서를 보면서 풉니다. 도장을 찍고 **사본 한 장을 받습니다**(계약서는 꼭 한 장 받아 보관).
- **감정 포인트**: 3번 질문에 점장이 답합니다. "말해줘서 고마워요. 그건 연우 씨가 일을 잘하게 돕는 방법이에요."

### 1일 차: 첫 출근
- 출근 기록부에 시간 쓰기 → 사물함과 유니폼 → **손 씻기 6단계**(포스터를 보며 순서대로).
- 매장 둘러보기 중 주방에서 반죽기 소리에 깜짝 놀랍니다. **민재**가 귀덮개를 보여 줍니다. "나도 해솔학교 나왔어."
- **소라의 애매한 지시**: "연우 씨, 저기 그거 좀 갖다줄래요?" → **확인 질문**: "어떤 것을 어디에서 가져올까요?" → 소라가 깨닫습니다. "아, 내가 너무 대충 말했네요!" (그림 카드 편의를 골랐다면 소라가 바로 쪽지에 그림을 그려 줍니다.)
- 퇴근 인사와 퇴근 기록.
- **감정 포인트**: 민재의 "괜찮아." 연우는 처음으로 '나 같은 사람'이 일하는 모습을 봅니다.

### 2일 차: 쏟아진 시럽
- 메모 확인 → 컵·빨대 채우기(투명 컵은 오른쪽, 종이컵은 왼쪽) → 환기.
- **시럽 사고**: 뚜껑이 덜 닫힌 바닐라 시럽이 카운터에 쏟아집니다. 화면이 잠깐 멈춘 듯 조용해지고 메모 3번이 눈에 들어옵니다.
- 연우: "선배님! 제가 시럽을 쏟았습니다!" / 도현: "말해줘서 고마워요." / 연우: "혼 안 내시나요?" / 도현: "혼을 왜 내요? 같이 닦아요."
- 점장이 문 푯말을 OPEN으로 돌리고 첫 손님 봉순 할머니가 들어옵니다. **"어서 오세요! 카페 마일스톤입니다!"**
- **감정 포인트**: "혼 안 내시나요?"에 담긴 오래된 두려움이 풀리는 순간.

### 3일 차: 손님 맞이
- 메모: 웃으며 인사하기 / 주문서를 손가락으로 짚으며 확인하기 / 트레이는 두 손으로.
- 봉순 할머니가 연우의 이름을 묻습니다. 연우는 할머니의 주문(소금빵, 따뜻한 우유)을 기억해 둡니다.
- **주문서 확인 미니게임**: 주문서와 트레이를 하나씩 짚어 맞춥니다.
- 고민하는 대학생 → 추천 메뉴 안내. 소라가 너무 빨리 말할 때 → "천천히 한 번 더 말씀해 주세요."
- **서진 손님**: 묻지 않고 휠체어를 밀어 주는 것은 실례입니다. "트레이를 자리까지 가져다드릴까요?" 서진: "네, 고마워요. 물어봐 줘서 더 고마워요."
- **감정 포인트**: 서진의 마지막 말. 연우가 늘 받던 존중을 이번에는 연우가 건넵니다.

### 4일 차: 낯선 손님들
- 메모: 순서대로 차분하게 / 혼자 정하기 어려우면 선배에게 / 불편한 일은 '어려워요'라고 말하기.
- **최 대리의 재촉**: "주문하신 순서대로 빠르게 준비하고 있습니다." → 도현: "손님이 화를 내도 연우 씨 잘못이 아니에요."
- **주문 실수**: 아이스를 따뜻한 것으로 만들었습니다. 사과하고, 다시 만들고, 선배에게 알립니다.
- **루나의 카메라**: "직원분도 같이 찍어요~ 웃어 봐요!" → **"죄송하지만 제 얼굴은 찍지 말아 주세요."** 라테 모양 재요청은 혼자 정하지 않고 선배에게 묻습니다.
- **도현의 실수**: 우유 주문을 깜빡한 도현이 점장에게 먼저 보고합니다. 점장: "말해줘서 고마워요." 연우는 깨닫습니다. **선배도 실수를 말하는구나.**
- **감정 포인트**: 처음으로 '싫다'고 말한 연우에게 도현이 하는 말. "싫은 건 싫다고 말해도 돼요. 그건 무례한 게 아니라 나를 지키는 거예요."

### 5일 차: 마감과 티타임
- 메모: 쏟아진 곳엔 주의 표지판 먼저 / 쉬는 시간엔 쉬기 / 퇴근 전 정리는 체크리스트대로.
- **장바구니 아주머니**가 빨대와 주스를 쏟고 떠납니다. 표지판을 먼저 세우고 → 닦습니다.
- **티타임(11:00)**: 쉬는 시간에 도현과 차를 마십니다. 동료에게 물어봐도 되는 것과 아닌 것(월급, 연애, 외모 같은 질문은 실례)을 배웁니다. 그리고 **도현의 과거 이야기**를 듣습니다.
- **퇴근 전 정리**: 체크리스트 미니게임.
- **저녁, 집 앞 정류장**: 엄마가 기다리고 있습니다. "엄마, 나 혼자 올 수 있어." 엄마: "…알아. 그래도 오늘은 같이 걷자." 첫 주 돌아보기(마일스톤 수첩).
- **감정 포인트**: 도현의 고백. "그래서 나는 연우 씨가 실수를 말해 줄 때마다 고마워요. 진짜로요."

### 3장: 피크타임
- 아침 메모: 숨 고르기 / 역할 나누기 / 어려우면 바로 말하기.
- **11:50 등산복 아저씨**: "야! 여기 왜 이렇게 늦어?" → 한 걸음 물러서서 "점장님!" → 점장이 단호하게 직원을 보호합니다.
- **12:30 단체 손님 15명**: 소리가 겹치고 화면 가장자리가 흐려집니다(차분 모드에서는 약하게 표현).
  - 귀마개를 요청했었다면: 앞치마 주머니에서 귀마개를 꺼냅니다. **실제로 소리가 먹먹해집니다**(오디오 필터).
  - 요청하지 않았다면: 도현이 묻고, 연우가 그 자리에서 요청합니다. "소리가 너무 커요. 귀마개를 써도 될까요?" 또는 "잠깐 쉬어도 될까요?"
  - 숨 세 번 → 역할 나누기: "선배님, 제가 포장과 뚜껑을 맡을게요. 음료는 선배님이 해 주세요."
- **제빙기 고장**: 손대지 않고 점장에게 알립니다 → 손님 안내 문장을 고릅니다.
- **13:20 배지 수여**: 점장이 메모의 비밀을 이야기합니다. **정규 크루 배지(MILESTONE CREW)**를 달아 줍니다. 도현: "오늘은 연우 씨가 나한테 역할을 정해 줬어요. 내가 배웠어요." 하이파이브. 민재는 주방에서 엄지를 듭니다. 소라가 '오늘의 한 장'을 찍습니다.
- **감정 포인트**: 점장의 고백. 도움이 '연우를 위한 특별한 것'이 아니라 **'모두를 위한 것'**이었다는 반전입니다.

### 3장 마무리: 나의 첫 메모 (`epilogue`, 2026-10-14 '에필로그'에서 이름을 바꿈)
- **다음 달 10일 아침**: 휴대폰에 입금 알림이 옵니다. 점장이 급여명세서를 건넵니다. 명세서 읽기(일한 시간, 주휴수당, 공제, 받은 돈). 월급 계획 세우기(저축, 생활, 선물).
- **10:00 문 앞의 신입 지호**: 단추를 만지작거리는 지호. 연우는 1장의 도현과 같은 말을 합니다. **"많이 긴장했죠? 어깨에 힘을 조금 빼도 괜찮아요."**
- 점장: "연우 씨가 지호 씨에게 첫 메모를 써 줄래요?" → **플레이어가 직접 고른 3가지 팁**으로 연우의 메모가 완성되어 점장의 메모 옆에 붙습니다.
- **저녁, 집**: 엄마에게 선물과 쪽지를 건넵니다. "엄마, 모르면 물어볼게요. 그러니까 걱정은 조금만 해요." 엄마: "…그래. 이제 걱정 조금만 할게."
- **마지막 서술**: "노란 메모가 한 장 더 붙었다. 이번에는 내 글씨다." → "나의 첫 번째 이정표. 마일스톤." → 연우의 속마음 "다음 주에는 또 어떤 일이 기다리고 있을까?"
- **3막의 끝이지 게임의 끝이 아닙니다**(2026-10-14). 크레디트·엔딩 영수증·작별 인사는 4막을 마친 뒤의 **엔딩**으로 옮겼습니다. 이야기는 다음 주 화요일의 4장(장 제목 '4장 · 자립 근무')으로 이어집니다.

### 엔딩: 다음 이정표 (`ending`, 4막을 처음 마친 뒤)
- **나오는 때**: 이야기의 마지막 에피소드(지금은 4장 1화)를 처음 마치면 결과 화면에 [엔딩 보기]가 나옵니다. 근무표의 '엔딩' 칸에서 언제든 다시 볼 수 있습니다. 판단·도장·일기가 없는 감상 장면입니다.
- **13:30 퇴근 인사(직원 공간)**: 앞치마를 접은 연우. 도현 "문 앞에서 떨던 연우 씨가, 이제 하루를 혼자 짜요." 오후 근무를 온 지호 "저도 언젠가 짜 보고 싶어요." 점장 "내일 근무판도 기대할게요." 민재는 주방 창문 너머로 손을 흔들고, 소라는 카메라를 듭니다.
- **21:30 연우의 방(프롤로그 첫 장면의 되풀이)**: 같은 책상, 선생님과 만든 일정표. 이번에는 **내일 일정표를 혼자 씁니다.** 김선영 선생님의 문자, 연우의 답장 "세 가지 약속 다 써 봤어요." 엄마가 프롤로그와 같은 말로 들어옵니다("연우야, 아직 안 자?"). 엄마: **"엄마는 이제 걱정 대신 응원할게."** 일정표 맨 아래에 꿈을 적습니다: "언젠가, 내가 만든 빵을 진열대에 놓기." 알람을 7시에 맞추고 불을 끕니다.
- **지나온 날들**: 사진 벽에 모은 '오늘의 한 장'이 한 장씩 붙으며 제목을 읽어 주고, 크레디트(크루·응원한 사람들·손님들·그리고 함께 일한 플레이어)가 떠오릅니다. 엔딩 음악.
- **다음 날 아침, 가게 앞**: 프롤로그에서는 도현이 문을 열어 주었지만, 이번에는 **연우가 스스로 유리문을 엽니다.** "안녕하세요! 오늘도 잘 부탁드립니다!"
- **연우의 마지막 메모**: 노란 메모에 플레이어 이름 → ① 모르면 물어봐요 ② 실수하면 바로 말해요 ③ 힘들면 쉬겠다고 말해요 → "함께해 줘서 고마워요. 우리는 같이 일하니까요!" → **직업 마1스톤 엔딩** 영수증('완결'은 4장 2~4화가 더 들어올 예정이라 쓰지 않음).
- **엔딩 뒤**: 처음 본 학생에게 "모든 이야기가 열렸어요. 근무표에서 하고 싶은 이야기를 골라요. 언제든 다시 할 수 있어요."(음성) → 근무표. 이 안내는 근무표의 엔딩 칸 옆에도 늘 보입니다.
- 4장 2~4화가 생기면 엔딩은 저절로 마지막 화 뒤로 옮겨 갑니다. 그때 퇴근 인사(지호·도현) 대사를 맞춰 고칩니다.

## 7. 선택, 실패, 되감기 (분기 설계)

### 7.1 판단 카드 = 시행착오의 무대
- 판단 장면마다 카드 2~4장이 나옵니다. 좋은 선택은 이야기를 이어 가고, **나쁜 선택은 짧은 '결과 장면'**을 보여 줍니다.
- 결과 장면이 끝나면 **'아차!' 카드**가 뜹니다. 무엇이 일어났는지와 왜 그런지를 한 줄로 알려 주고, 큰 **[⏪ 되감기]** 버튼 하나만 둡니다.
- 되감기를 누르면 회중시계 바늘이 거꾸로 돌고, **선택 직전 순간**으로 돌아갑니다. 한 번 고른 카드에는 '⏪ 해 봤어요' 표시가 남습니다.
- 결과 장면은 **원인과 결과가 한눈에 보이게** 씁니다(숨겼다 → 10분 뒤 → 손님이 미끄러짐). 과장된 공포나 모욕은 쓰지 않습니다.
- 발견한 실패는 **아차 노트**에 모입니다. 일부러 다른 카드를 골라 보는 것도 배움이고 놀이입니다.
- 화면 오른쪽 위 **[⏪ 되감기]**로 지난 판단 장면 어디로든 언제든 돌아갈 수 있습니다.

### 7.2 도장 단계
| 결과 | 도장 |
| :--- | :--- |
| 도움 없이 한 번에 좋은 선택 | ★★★ 스스로 |
| 아차(되감기)·메모 강조·'도와주세요'를 받고 좋은 선택 | ★★ 조금 도움 |
| 정답 카드가 반짝일 때 좋은 선택 | ★ 함께 |

판단 카드의 별은 몇 번 골랐는지가 아니라 **고를 때 보인 도움**으로 정합니다. 정답 카드는 '도와주세요'를 두 번 누르거나, 되감은 뒤 도움 설정에 따라 틀린 횟수가 쌓이면(많이 1번 · 보통 2번 · 스스로 3번) 반짝입니다. 미니게임·면접은 시도·실수 횟수로 정합니다.

에피소드는 언제든 다시 할 수 있어서, 별 세 개를 모으는 것도 다시 하기의 동기가 됩니다.

### 7.3 플래그 (선택 기억)

> 판단 카드와 달리 아래 선택에는 정답이 없습니다. 무엇을 골라도 이야기가 이어지고, 고른 내용이 뒤에서 다시 등장합니다.

| 플래그 | 정해지는 곳 | 값 | 회수되는 곳 |
| :--- | :--- | :--- | :--- |
| `calmStyle` | 1장 도입 | `breath` / `tidy` | 1장 면접 직후 도현의 대사 |
| `accommodation` | 1장 면접 3번 | `earplugs` / `pictures` / `slowly` / `later` | 1일 차(민재·소라), 3장(과부하 장면 전체) |
| `askedQuestion` | 1장 면접 4번 | `true` / `false` | 1장 점장의 마무리 말 |
| `firstFeeling` | 매 에피소드 돌아보기 | 5가지 기분 | 교사 보고서(정서 기록), 3장 마무리 일기 회상 |

## 8. 문체 가이드: 쉬운 한국어로 감동 주기

### 8.1 기본 규칙
1. **대사 한 칸은 두 문장 이내**, 한 문장은 되도록 **35자 이내**로 씁니다.
2. 한 문장에는 **한 가지 정보**만 담습니다.
3. **비유와 관용 표현은 아껴 씁니다.** 꼭 필요하면 `{{말 사전}}` 표시로 뜻을 함께 줍니다. 예: `{{손이 빠르다}}`
4. 감정은 이름 대신 **몸과 감각**으로 씁니다. "무서웠다"보다 "손끝이 차가워졌다"가 낫습니다.
5. 숫자와 시간은 **아라비아 숫자**로 씁니다(오전 8시 50분 → 08:50 또는 8시 50분).
6. 일터의 말은 **실제로 따라 할 수 있는 문장**이어야 합니다. 정답 카드의 대사는 그대로 외워서 써도 되는 '모범 문장'입니다.
7. 높임말은 일관되게 씁니다. 직원끼리는 해요체, 손님에게는 하십시오체와 해요체를 섞어 정중하게, 연우의 속마음은 반말로 씁니다.

### 8.2 고쳐 쓰기 예시
| v1 (피하기) | v2 (권장) | 이유 |
| :--- | :--- | :--- |
| 우리는 톱니바퀴처럼 움직이기 시작했다. | 선배가 음료를 만들고, 나는 뚜껑을 닫았다. 하나씩, 차례대로. | 비유 대신 실제 행동 |
| 발달장애가 있는 나에게 소음은 가장 무서운 자극이다. | 소리가 한꺼번에 몰려왔다. 귀가 멍멍했다. 발이 바닥에 붙은 것 같았다. | 진단명 라벨링 금지, 감각으로 보여 주기 |
| 발달장애 학생이 가장 무서워하는 순간. | (삭제) | 일반화·고정관념 금지 |
| 컵 정리도 칼같이 해뒀군. | 컵도 크기별로 반듯하게 쌓았네요. | 관용 표현 대신 구체적 칭찬 |
| 백배 천배 훌륭한 거예요. | 바로 말해 준 게 제일 중요해요. | 과장 대신 이유가 있는 칭찬 |

### 8.3 피드백 문장 공식
- **칭찬 = 구체적 행동 + 그 행동이 좋은 이유**
  - "바로 말해줘서 고마워요. 그래서 손님이 미끄러지지 않았어요."
- **아차! 카드 = 일어난 일(제목) + 왜 그런지 + 대신 할 행동** (두 문장 이내)
  - 제목: "손님이 미끄러졌어요"
  - 교훈: "쏟은 것을 숨기면 다른 사람이 다칠 수 있어요. 바로 말하고 같이 닦아요."
- **힌트('도와주세요' 버튼) = 마음 인정 + 볼 곳(메모 번호) + 생각할 질문**
  - "그 마음 알아요. 메모 3번을 같이 볼까요? 실수하면 어떻게 하기로 했죠?"
- **결과 장면 원칙**: 인물을 모욕하거나 위협하지 않습니다. 결과는 분명하게, 표현은 담담하게.
- **금지어**: 바보, 느려요, 왜 그것도 몰라요, 넌 안 돼. (게임 화면의 '아차!'는 괜찮습니다.)

| 연우를 성실한 성인 직원으로 그린다 | 아이처럼 다루거나 반말로 낮춘다 |
| 특성을 행동과 감각으로 보여 준다 | 서술에서 진단명으로 부른다 |
| 도움(편의)을 당연한 업무 도구로 그린다 | 도움을 '특별한 배려'나 '동정'으로 그린다 |
| 다른 직원도 실수하고, 보고하고, 도움을 쓴다 | 연우만 실수하고 연우만 도움받는다 |
| 연우가 스스로 고르고 말하게 한다 | 다른 사람이 연우 대신 결정하고 말한다 |
| 어려운 손님은 '사정 있는 사람'으로 그린다 | 손님을 악당이나 웃음거리로 그린다 |
| 감동은 연우의 **선택과 말**에서 나온다 | 감동을 장애 극복 서사에서 짜낸다 |

---

## 10. 말 사전(Glossary) 정책
- 일터에서 실제로 듣게 되는 말, 관용 표현, 노동 용어를 그림과 쉬운 설명으로 모읍니다.
- 대사 속 `{{낱말}}`은 밑줄로 표시되고, 누르면 뜻을 보여 주고 읽어 주며, 마일스톤 수첩의 **말 사전**에 수집됩니다.
- 예: 근로계약서, 주휴수당, 휴게시간, 급여명세서, 공제, 손이 빠르다, 눈치, 마감, 피크타임, 재고, 주의 표지판, 편의(도움), 고객응대근로자 보호.
- 전체 목록은 `js/data/glossary.js`에 있습니다.

# 직업 마1스톤: 교사용 지도서

> 대상: 특수학교 고등부·전공과, 특수학급, 직업재활 기관
> 연계: 2022 개정 특수교육 기본교육과정 고등학교 「진로와 직업」(성취기준 원문은 PRD 3장, 게임 안 교사 보고서에도 표시)

---

## 1. 이 프로그램의 수업 원리

1. **실패해 보고, 되감아 다시 하기.** 나쁜 선택을 하면 실제로 어떤 일이 생기는지 짧은 장면으로 보여 주고, 회중시계로 바로 그 선택 앞으로 돌아갑니다. 학생이 "아, 그래서 바로 말해야 하는구나"를 **스스로 발견**하게 하는 것이 목표입니다.
2. **정답 카드의 문장은 그대로 따라 말할 문장입니다.** 플레이 뒤 역할극에서 소리 내어 연습하세요.
3. **틀린 길을 일부러 가 보는 것도 학습입니다.** 아차 노트(실패 결과 모음)를 채우는 것을 수업 활동으로 써도 좋습니다.

## 2. 수업 준비 (처음 한 번)

1. 처음 화면 → **선생님 모드**(처음 번호 `1234`, 바로 바꾸세요) → **학생 추가**로 학생마다 프로필을 만듭니다. **이름은 본명 대신 별명**으로 만들고, 누구의 별명인지는 선생님 명부에 따로 적어 두세요. 이 게임은 생성형 AI로 만든 그림·음성을 쓰고(선택 기능인 AI 면접관이나 웹판의 브라우저 음성·음성 인식처럼) 글이 인터넷으로 나갈 수 있는 경우를 모두 막을 수는 없어서, 처음부터 개인 정보가 들어가지 않게 하는 방법을 씁니다. 자세한 내용: 선생님 모드 → 제작·저작권 정보 → 데이터.
2. 학생별 **설정**을 맞춥니다. 처음 하는 학생은 **프롤로그부터** 시작하세요. 프롤로그가 조작 연습(튜토리얼)을 겸하고, 처음 보는 버튼에는 무지개 테두리와 손가락이 나옵니다(설정 → '처음 보는 버튼 알려 주기'에서 끄거나 처음부터 다시 볼 수 있음). 글자 크기, 읽어 주기(읽기가 어려우면 '자동으로'), 차분 모드(소리·빛에 예민하면), 두 번 눌러 고르기(손 조절이 어려우면), 자동 스캔(스위치 사용)을 정한 뒤 필요하면 **설정 잠그기**를 켭니다.
3. **시간 제한**(설정 → 진행): 손님이 기다리거나 바닥이 젖은 것처럼 이야기 속에서 급한 장면(2일 차 첫 손님, 4일 차 재촉하는 손님, 5일 차 쏟아진 주스, 3장 피크타임)에는 줄어드는 막대가 나옵니다. 처리 속도가 느리거나 손 조절이 어려운 학생은 '넉넉히'(2배)나 '끄기'로 맞추세요. 자동 스캔을 켜면 저절로 꺼지고, 같은 장면에서 두 번 넘게 실패하면 막대 없이 다시 해요.
4. 수업 진도에 맞춰 **모든 이야기 열기**를 켜면 원하는 에피소드로 바로 갈 수 있습니다. 4장(자립 근무)을 마치고 **엔딩**까지 본 학생은 이 설정과 상관없이 모든 이야기가 늘 열립니다(근무표에서 골라 다시 하기·엔딩 다시 보기).
5. 헤드폰을 권장합니다. 교실 전체로 할 때는 스피커 음량을 낮게 시작하세요.
6. 로컬 LLM(Ollama)이 설치된 PC라면 선생님 모드에서 **연결 시험**을 해 보세요. 없어도 면접은 정상 진행됩니다.

## 4. 수업 운영 방식

- **개별형**: 학생마다 PC나 태블릿으로 합니다. 기록이 학생별로 남습니다.
- **전체형(전자칠판)**: 교사가 진행하고, 판단 카드가 나오면 학생들이 손가락이나 카드로 투표합니다. 다수결로 나쁜 선택이 나와도 그대로 가서 결과를 함께 봅니다. 그다음 되감기를 하세요.
- **짝형**: 한 명은 대사를 소리 내어 읽고, 다른 한 명이 고릅니다. 판단 장면마다 역할을 바꿉니다.
- **기록 옮기기·보관하기(기록 파일)**: 기록은 그 기기(웹판은 그 브라우저)에만 남습니다. 재부팅하면 원래대로 돌아가는 학교 PC(복원 프로그램)나 자리를 바꾸는 수업에서는 끝날 때 **[기록 파일로 저장]**을 누르세요(불러오기·저장하기 화면 아래, 또는 선생님 모드). 브라우저는 다운로드 폴더에 바로 저장하고, 설치용 앱은 저장할 곳을 묻습니다. 다운로드 폴더도 함께 지워지는 PC라면 파일을 USB나 학교 드라이브로 옮겨 두세요.
  - 다음 시간: 처음 화면의 **[기록 파일로 이어 하기]**(이 기기에 학생이 없을 때), 또는 **학생 바꾸기 → [기록 파일 불러오기]**로 그 파일을 고릅니다. 같은 학생의 기록은 **합쳐지고 지워지는 것은 없습니다.** 옛 파일을 불러와도 더 최근 기록이 남습니다.
  - 선생님 모드의 **[학급 전체 저장]**은 이 기기의 모든 학생을 파일 하나로 저장합니다. 학생들이 저마다 저장한 파일을 **[기록 파일 불러오기]**에서 한꺼번에 골라 선생님 PC로 모으면 보고서를 함께 볼 수 있습니다.
  - 기록 파일은 서버로 보내지 않습니다. 별명과 학습 기록이 들어 있으니 학교 지침에 맞는 곳에 두고, 다 쓴 파일은 지우세요. 선생님 번호는 파일에 들어가지 않습니다.

## 5. 에피소드별 지도안

### 프롤로그 · 첫 출근길 (약 8분)
- **목표**: 준비 시간을 계산해 알람을 맞춘다. 버스 번호를 끝까지 확인한다. 긴장을 다스린다.
- **모범 문장**: "혼자 가 볼게요. 연습했어요." / "해솔07 맞아요?"
- **성취기준**: [12진로04-02] [12진로04-03] [12진로01-02]
- **사전 활동**: 우리 학교에서 현장실습지까지 가는 버스 번호를 찾아보기
- **조작 연습**: 프롤로그 안내(대사 넘기기·밑줄 낱말·메모·카드·되감기·다시 듣기·수첩·숨 고르기·멈춤)를 학생이 직접 눌러 보게 하세요. 무지개 테두리가 도는 버튼이 '지금 처음 보는 버튼'입니다
- **토의**: 알람을 몇 시에 맞춰야 할까? 계산해 볼까? / 헷갈리는 버스 번호가 오면 누구에게 물어볼까?
- **확장**: 실제 등굣길 버스 정류장 사진으로 '번호 끝까지 읽기' 연습

### 1장 · 첫 관문: 면접과 계약 (약 15분)
- **목표**: 노크하고 들어간다. 강점을 말한다. 실수를 숨기지 않겠다고 말한다. 필요한 도움을 말한다. 질문한다. 근로계약서의 시간·휴게·월급날을 확인한다.
- **모범 문장**: "들어가도 될까요?" / "제가 컵을 깨뜨렸다고 바로 말씀드리겠습니다." / "큰 소리가 나면 놀라요. 귀마개를 써도 될까요?" / "다시 한번 말씀해 주시겠어요?" / "생각할 시간을 주실 수 있나요?"
- **성취기준**: [12진로06-02] [12진로01-03] [12진로04-01] [12진로04-05]
- **관찰**: 면접 대답 방법(골라서·글자·말)을 무엇으로 골랐는지, '다시 말해 주세요'를 썼는지
- **면접 방식**: 4문항 중 3개를 알맞게 대답하면 합격입니다. 틀려도 바로 되감지 않고 끝까지 본 뒤, 모자라면 **탈락 엔딩**(다음 날 불합격 문자) → **면접 돌아보기**(문항별 내 대답·이렇게 말해요·이유) → [면접 다시 보기]로 처음부터 다시 봅니다. 미리 "떨어져도 다시 볼 수 있어요"라고 안내하세요.
- **로컬 LLM**: 연결되어 있지 않으면 '골라서 말하기'만 나옵니다(대본 반응). 연결되면 글자·말로도 대답할 수 있고 점장님 반응을 LLM이 만듭니다.
- **토의**: 면접에서 "모르겠어요"라고 해도 될까? / 내가 일할 때 필요한 도움은 무엇일까?(학생 자신의 편의 목록 만들기)
- **확장**: 실제 표준근로계약서 양식으로 '일하는 시간·쉬는 시간·시급' 찾기

### DAY 1 · 첫 출근 (약 10분)
- **목표**: 출근 기록을 쓴다. 손을 6단계로 씻는다. 애매한 지시에 확인 질문을 한다. 퇴근 인사를 한다.
- **모범 문장**: "어떤 것을 어디에서 가져올까요?" / "먼저 들어가 보겠습니다. 수고하셨습니다!"
- **성취기준**: [12진로04-02] [12진로03-01] [12진로03-02] [12진로04-04] [12진로04-05]
- **관찰**: 손 씻기 미니게임에서 포스터를 보는지(실수 횟수)
- **토의**: "그거 좀 가져와"라는 말을 들으면 어떻게 할까? / 민재 선배는 왜 귀덮개를 쓸까?
- **확장**: 교실 세면대에서 손 씻기 6단계 실습

### DAY 2 · 쏟아진 시럽 (약 10분)
- **목표**: 메모 순서대로 준비한다. 컵을 분류한다. **실수를 바로 보고한다.** 끈적한 것을 올바르게 닦는다. 첫 손님에게 인사한다.
- **모범 문장**: "선배님! 제가 시럽을 쏟았습니다!" / "어서 오세요! 카페 마일스톤입니다!"
- **성취기준**: [12진로03-01] [12진로04-04] [12진로04-01] [12진로03-04] [12진로04-05]
- **핵심 장면**: 시럽 사고. 세 갈래 결과(모르는 척 → 손님이 미끄러질 뻔함, 몰래 닦기 → 더 번짐, 바로 말하기 → 같이 해결)를 **모두 보여 준 뒤** 비교 토의하면 효과가 큽니다.
- **토의**: 혼날까 봐 무서울 때 어떻게 말을 시작할까? / 도현 선배는 왜 혼내지 않았을까?
- **확장**: '실수 보고 문장' 카드 만들기: "선배님, 제가 ○○을/를 ○○했습니다."

### DAY 3 · 손님 맞이 (약 10분)
- **목표**: 단골 손님을 반갑게 맞는다. 주문서를 짚어 확인한다. 고민하는 손님에게 추천 메뉴를 안내한다. 빠른 말에 다시 묻는다. **도움은 먼저 묻는다.**
- **모범 문장**: "천천히 한 번 더 말씀해 주세요." / "트레이를 자리까지 가져다드릴까요?"
- **성취기준**: [12진로04-05] [12진로04-04] [12진로03-02] [12진로04-02]
- **핵심 장면**: 휠체어 사용 손님. "도와주는 것도 먼저 묻는다"는 존중을 다룹니다.
- **토의**: 묻지 않고 도와주면 왜 안 될까? / 내가 도움을 받을 때 어떻게 해 주면 좋을까?

### DAY 4 · 낯선 손님들 (약 10분)
- **목표**: 재촉하는 손님에게 차분히 안내한다. 내 실수를 사과하고 고친다. **싫은 것을 정중하게 거절한다.** 정하기 어려운 일은 선배에게 묻는다.
- **모범 문장**: "주문하신 순서대로 빠르게 준비하고 있습니다." / "죄송합니다. 바로 다시 만들어 드릴게요." / "죄송하지만, 제 얼굴은 찍지 말아 주세요."
- **성취기준**: [12진로04-05] [12진로04-01] [12진로01-02]
- **토의**: 거절은 무례한 걸까? / 손님이 화를 내면 내 잘못일까?(도현: "연우 씨 잘못이 아니에요.")
- **확장**: 거절 문장 연습: "죄송하지만, 그건 어려워요."

### DAY 5 · 마감과 티타임 (약 10분)
- **목표**: 쏟아진 곳에 표지판부터 세운다. 쉬는 시간을 쓴다. 동료에게 할 수 있는 질문과 사적인 질문을 구분한다. 체크리스트로 정리한다.
- **모범 문장**: "선배님은 주말에 뭐 하세요?"

- **감정 장면**: 도현의 과거 고백(실수를 숨겨 손님이 다침). 2일 차 시럽 장면과 연결해 이야기 나누기
- **토의**: 동료에게 물어봐도 되는 것과 조심할 것은? / 엄마는 왜 정류장에서 기다렸을까?

### 3장 · 피크타임 (약 15분)
- **목표**: 폭언 손님은 혼자 상대하지 않고 관리자를 부른다. 소리가 클 때 필요한 도움을 말한다. 역할 분담을 먼저 제안한다. 고장 난 기계를 만지지 않고 보고한다. 손님에게 안내한다.
- **모범 문장**: "점장님! 잠깐 와 주시겠어요?" / "소리가 너무 커요. 귀마개를 써도 될까요?" / "2분만 쉬고 와도 될까요?" / "제가 포장을 맡을게요. 음료는 선배님이 해 주세요." / "얼음이 부족해서 아이스 음료는 10분 정도 걸려요. 따뜻한 음료는 바로 돼요."

## 7. 안전과 정서 유의 사항
- 실패 결과 장면(손님이 미끄러짐, 면접 탈락, 반말 손님)은 담담하게 표현했지만, 과거 비슷한 경험이 있는 학생은 불편할 수 있습니다. **미리 장면을 안내**하고 언제든 [숨 고르기]·[멈춤]을 쓸 수 있다고 알려 주세요.
- 소리·빛에 예민한 학생은 **차분 모드 + 움직임 줄이기 + 음량 작게**로 설정하세요. 3장 과부하 장면도 약하게 표현됩니다.
- 기분 기록에서 '힘들어요'가 이어지면 짧게 면담하고 진도를 조절하세요.

## 8. 자주 묻는 질문
- **소리가 안 나와요.** 브라우저는 첫 클릭 뒤에 소리가 납니다. 설정에서 '전체 소리'를 확인하세요.
- **읽어 주는 목소리가 기계 같아요.** 미리 만든 음성 파일(Supertonic)이 있으면 그 목소리로, 없으면 브라우저 목소리로 읽습니다. 담당자가 `npm run voices`로 음성을 만들 수 있습니다.
- **말로 대답하기가 안 돼요.** 기기나 앱에 따라 음성 인식을 쓸 수 없습니다. 골라서 말하기나 글자로 쓰기를 쓰세요.
- **학생 기록이 사라질까 봐 걱정돼요.** 기록은 이 기기(브라우저)에 저장됩니다. **[기록 파일로 저장]**으로 파일을 만들어 USB나 학교 드라이브에 보관하고, 다른 PC에서는 그 파일을 불러와 이어 합니다(4. 수업 운영 방식 → 기록 옮기기). 보고서는 인쇄나 CSV로도 남길 수 있습니다.
